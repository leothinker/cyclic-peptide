Phase 2 Task 1 - reference status, three flags kept separate

These three columns answer different questions and must never be
collapsed into one another:

  transcription_admissible  can this string be used as CER ground
                            truth? (|delta| <= 5 Da)
  text_reference_human_ver  did a person read the printed cell back
                            character by character? (CHARACTERS only)
  mass_gate_verdict         does the patent m/z check accept it?
  structure_verified        has a human confirmed the chemistry?
                            (always 'no' in this project)
