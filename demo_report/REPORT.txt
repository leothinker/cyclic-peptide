# Morning-report demos -- consolidated

Each demo writes to its own ``demo_*`` folder. Run any of them individually with ``.venv\Scripts\python.exe -u _demo_*.py``.

## RapidOCR top-k demo

- script: ``_demo_topk.py``
- output: ``demo_rapidocr_topk/``
- exit code: 0
- reportable claim: Confirms per-character top-k OCR is wired end-to-end: each character emits a top-3 candidate list with softmax probabilities. CH and EN recognisers both expose it. The underlying patch lives in `.venv/Lib/site-packages/rapidocr/ch_ppocr_rec/main.py` and the mirror copy is in `references/RapidOCR/...`.

## Hiro-OCSR classify_smiles sweep

- script: ``_demo_hiro.py``
- output: ``demo_hiro_classify/``
- exit code: 0
- reportable claim: The `hiro_ocsr.classify.classify_smiles` post-processor runs in pure RDKit+regex (no LLM, no GPU) and categorises each DECIMER SMILES as molecule / fragment / markush / irregular / invalid. We label all 405 entries to validate Hiro's stack before deploying the 8B-VLM inference path overnight.

## DECIMER per-token confidence distribution

- script: ``_demo_decimer_conf.py``
- output: ``demo_decimer_conf/``
- exit code: 0
- reportable claim: DECIMER-AI's `predict_SMILES(confidence=True)` exposes per-token softmax; the cache keeps `min_conf` and `low_conf_count` summaries. 77% of our 405 cmpds have at least one low-conf token; the rest cluster at 0.3-0.5 min_conf. Per-position truncation post-processing remains available; we just need a re-run with per-token storage to exercise it on the live cache.
